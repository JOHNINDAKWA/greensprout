# GreenSprout corrective patch

Apply after the earlier lawn-services and grooming-mower patches. It restores the **full** service page template for Hydroseeding, Erosion control, Landscape establishment and Land rehabilitation: explanations, suitability cards, benefits, process, gallery and hydroseeding FAQ remain visible. Each planned service receives a prominent dark Coming Soon banner after its hero, and its enquiry language identifies future availability.

Four illustrative action images have been revised again using the exact supplied GreenSprout Hydroseeding logo reference rather than the simplified leaf symbol on the proposed uniform. The real uploaded logo asset is included unchanged at `public/brand/greensprout-logo.png`. Tiny AI-generated embroidery cannot be treated as production artwork; use that master logo file when commissioning uniforms. No photos are represented as a completed GreenSprout project or owned equipment.

This ZIP is an overlay rooted at the existing project directory. It includes only changed files; extracting it over the previous installed phases updates the website directly.
